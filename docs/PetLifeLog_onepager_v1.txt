# 🐾 Project: PetLifeArchive (펫라이프아카이브)
> **"사진 한 장으로 기록하는 우리 아이의 특별한 순간"**
> Vision AI를 활용하여 반려견의 사진에서 데이터를 추출하고, 감성적인 1인칭 일기와 스마트한 도감을 자동으로 생성하는 아카이빙 플랫폼입니다.

---

## 1. 프로젝트 비전 (Project Vision)
사용자가 찍는 일상적인 사진을 단순한 파일로 두지 않고, AI를 통해 **의미 있는 데이터(일기, 유통기한, 선호도, 위치)**로 변환합니다. 번거로운 텍스트 입력 없이 사진 업로드만으로 반려견의 생애 주기를 완벽하게 기록하는 것을 목표로 합니다.

---

## 2. 핵심 기능 (Core Features)

### 🗓️ AI 포토 캘린더 & 1인칭 일기
- **메인 대형 캘린더:** 날짜별로 업로드된 사진 중 대표 사진이 썸네일로 박히는 비주얼 캘린더 UI.
- **AI 1인칭 일기:** 사진을 누르면 AI가 촬영 시간, 장소, 피사체를 분석하여 강아지의 시점에서 일기를 씁니다.
  - *예: "오늘 오후 3시, 서울숲에서 엄마랑 신나게 뛰었개! 날씨가 시원해서 혓바닥이 절로 나왔다 왈!"*

### 🍱 스마트 간식/장난감 도감
- **간식 정보 추출:** 간식 봉투 사진을 찍으면 AI가 제품명, 유통기한, 성분 등을 자동으로 캐치합니다.
- **지능형 가이드:** 반려견의 몸무게(kg)와 제품 정보를 매핑하여 '하루 권장 급여량'을 수치로 제공합니다.
- **주관적 선호도:** 사용자가 직접 하트/별점으로 강아지의 선호도를 기록하여 '최애 리스트'를 구축합니다.

### 👗 디지털 옷장 & 코디 아카이브
- **의류 등록:** 옷 사진을 찍어 올리면 AI가 색상과 종류(패딩, 티셔츠 등)를 분류합니다.
- **코디 연결:** 해당 옷을 입고 찍은 반려견의 사진을 자동으로 매칭하여 '실제 착용 샷' 갤러리를 형성합니다.

### 📍 애플 스타일 산책 포토맵
- **시각적 발자취:** 애플 사진 앱처럼 지도 위에 산책 중 찍은 사진들을 위치별 핀(사진 썸네일)으로 표출합니다.
- **공간 데이터 활용:** 별도의 트래킹 시작 없이도 사진의 EXIF 데이터를 파싱하여 주요 산책 경로와 추억의 장소를 시각화합니다.

---

## 3. 기술 스택 (Technical Stack)

- **Backend:** Java 17 / Spring Boot 3.x
- **Database:** PostgreSQL (PostGIS 확장 기능 사용 - 공간 데이터 처리)
- **Frontend:** Next.js / Tailwind CSS (지도 및 캘린더 인터랙티브 UI 구현)
- **AI Engine:** Google Gemini 1.5 Flash (Vision & Text Generation)
- **Security:** Spring Security & JWT (카카오 OAuth 2.0 연동 및 Refresh Token 관리)
- **Infrastructure:** Supabase (Database Hosting), Cloudflare R2 (Image Storage)

---

## 4. 백엔드 핵심 설계 포인트 (Backend Strategy)

1. **비정형 데이터의 정규화:** 이미지에서 추출된 AI 결과값(JSON)을 가공하여 RDBMS의 관계형 데이터로 정밀하게 변환 및 저장합니다.
2. **공간 쿼리 최적화:** PostGIS를 활용하여 지도상의 사진 데이터를 클러스터링하고, 현재 지도 영역(Bounding Box) 내의 사진들만 효율적으로 조회합니다.
3. **사용자 경험 자동화:** 사진 한 장으로 다중 테이블(일기, 장소, 도감)을 동시 업데이트하는 비즈니스 로직을 트랜잭션 단위로 관리합니다.

---

## 5. 서비스 흐름 (UX Flow)
1. **사진 업로드:** 사용자가 봉봉이의 사진(산책, 간식, 옷 등)을 업로드합니다.
2. **AI 분석:** 백엔드에서 Gemini Vision API를 호출하여 상황을 분석하고 메타데이터를 추출합니다.
3. **데이터 매핑:** 분석된 내용에 따라 캘린더, 도감, 포토맵이 실시간으로 업데이트됩니다.
4. **아카이브 완성:** 사용자는 별도의 타이핑 없이도 채워진 캘린더와 지도를 보며 추억을 회상합니다.
