# 📄 [One-Pager] 다꾸로그 (Daggulog) - AI Vision Edition
> **"복잡한 입력 없이, 사진 한 장으로 완성되는 AI 다꾸 창고"**

---

## 1. 서비스 개요
* **한 줄 소개**: Vision AI를 활용해 다꾸템을 자동 태깅 및 기록하고, 색감과 분위기로 내 취향을 탐색하는 서비스.
* **핵심 컨셉**: "Don't Type, Just Snap." (타이핑하지 말고 찍으세요.)

---

## 2. 기술 스택 (가성비 & 고성능 조합)
| 구분 | 기술 스택 | 비고 |
| :--- | :--- | :--- |
| **Frontend** | **Next.js (Vercel)** | 빠른 SSR 및 직관적인 UI 구현, Vercel 무료 배포 |
| **Backend** | **Spring Boot (Oracle Cloud)** | Ampere A1(24GB RAM) 인스턴스 활용, 안정적인 API 서버 |
| **Database** | **Supabase (Dev) → PostgreSQL (Prod)** | 서버리스 환경으로 시작해 추후 pgvector 확장을 위해 운영 환경 이관 |
| **Storage** | **Cloudflare R2** | Egress(아웃바운드 트래픽) 비용 없는 이미지 저장소 (S3 호환) |
| **AI Engine** | **Google AI Studio (Gemini 1.5 Flash)** | 이미지 분석, 텍스트 추출(OCR 대체), 자동 태깅 통합 수행 |

---

## 3. 핵심 기능 (AI 통합형)

### [수집 및 등록]
* **All-in-One Vision 분석**: 사용자가 사진을 올리면 AI가 이미지 내 글자(제품명/작가명)와 시각적 요소(색감/분위기/소재)를 한 번에 분석하여 추출.
* **Smart Tagging**: 포장지가 없더라도 이미지에서 추출한 키워드(예: `#분홍`, `#하트`, `#반짝이`)를 기반으로 자동 태그 생성.

### [탐색 및 검색]
* **비주얼 필터링**: 텍스트 검색창 대신 색상 스와치와 분위기 칩(Chip)을 클릭하여 결과를 즉시 필터링.
* **무한 갤러리**: 내가 가진 아이템을 핀터레스트(Pinterest) 스타일의 썸네일 피드로 한눈에 확인.

### [개인화 관리]
* **보관소 태깅**: 아이템별 물리적 보관 장소(예: 1번 바인더, 노란 서랍)를 함께 기록하여 실물 탐색 보조.
* **보유 통계**: 내 다꾸 취향(선호 색상, 카테고리 비율)을 시각화한 대시보드 제공.

## 4. 데이터 구조 (Core)

```sql
-- 개인 다꾸템 관리 테이블
CREATE TABLE items (
    id BIGSERIAL PRIMARY KEY,
    user_id BIGINT NOT NULL,
    image_url VARCHAR(255) NOT NULL, -- Cloudflare R2 링크
    product_name VARCHAR(100),       -- AI 추출 또는 사용자 수정 (null 허용)
    creator_name VARCHAR(100),       -- AI 추출 또는 사용자 수정 (null 허용)
    tags JSONB,                      -- AI 생성 태그 (예: ["핑크", "키치", "고양이", "펄"])
    storage_location VARCHAR(100),   -- 물리적 보관 위치
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

## 5. 단계별 로드맵 (AI-First)
###🟢 1단계: 미니 MVP (2주)

- 목표: "핵심 사이클 검증"
- 내용: 사진 업로드 → Gemini 분석(프롬프트 튜닝) → 태그 기반 갤러리 리스트 구현.

###🟡 2단계: UX 최적화 (1개월)

- 목표: "입력 허들 최소화"
- 내용: 모바일 연속 촬영(Fast Snap) 모드, 다중 필터 버튼 강화, 보관 위치 관리 로직 추가.

###🔵 3단계: 플랫폼화 (중기)

- 목표: "데이터 공유의 장"
- 내용: 유저 간 데이터 공유 설정, 공용 제품 DB 구축 및 이미지 벡터(pgvector) 기반 유사도 검색 도입.

## 6. 핵심 개발 전략
- Cost Efficiency (비용 방어): 프론트엔드에서 업로드 전 이미지 리사이징(용량 최소화) 후 Gemini 1.5 Flash 무료 티어 내에서 분석 처리.
- Fail-Safe UI (수정의 자유): AI 분석 결과는 언제나 '초안'으로 취급하며, 유저가 탭 한 번으로 태그나 텍스트를 직관적으로 삭제/수정할 수 있는 UI 제공.
- Vibe Coding: Cursor, Claude 등을 적극 활용하여 Spring Boot 보일러플레이트, API 매핑, Next.js 컴포넌트 마크업 속도 극대화.
