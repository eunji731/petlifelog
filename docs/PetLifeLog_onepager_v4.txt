# 🐾 Project: PetLifeArchive (펫라이프아카이브) `v3.0`

> **"사진 한 장으로 시작되는 다견 가정의 완벽한 일상 아카이빙"**
> GPT Vision AI와 메타데이터 추출 기술을 결합하여, 반려견의 일상을 별도의 입력 없이 **사진 업로드만으로** 자동 완성하는 백엔드 중심 플랫폼입니다.

---

## 1. 프로젝트 비전 (Project Vision)

사용자의 수기 입력 부담을 **제로(Zero)**화합니다.
사진 속 EXIF 데이터와 AI 비전 분석을 결합하여 **[캘린더 - 일기 - 지도 - 타임라인 - 도감]** 이 서로 유기적으로 연결되는 반려견 전용 데이터 생태계를 구축합니다. 단일 강아지 중심의 기록을 넘어, 다견 가정의 상호작용까지 완벽하게 담아냅니다.

---

## 2. 핵심 기능 (Core Features)

### 📸 Zero-Input Photo Flow (작성 자동화) `NEW`
* **입력에서 검수로 패러다임 전환:** 캘린더에서 작성 패널 진입 시, 최소한의 UI(사진 등록 및 가벼운 태그 입력란)만 노출합니다.
* **Auto-Fill 시스템:** 사진 업로드 즉시 AI가 사진을 분석하여 활동 종류, 날씨, 에너지 상태를 폼에 자동 바인딩합니다.
* **1-Click Save:** 사용자는 AI가 모두 채워둔 결과물과 감성 일기를 쓱 훑어보고 [저장하기] 버튼만 누르면 됩니다.

### ✍️ GPT 다견 멍멍 일기 (Multi-Dog AI Diary) `UPDATE`
* **다견 프로필 동시 주입:** 사진 속에 여러 마리가 함께 있다면, AI가 각 강아지의 등록된 외형/성격 프로필을 대조하여 누가 참여했는지 자동 인식(`dogs_detected`)하고 체크박스를 채웁니다.
* **1인칭/관찰자 시점 혼합:** 각 강아지의 특징(예: 날렵하게 뛰는 모습 vs 느긋하게 쉬는 모습)을 구분하여 한 편의 조화로운 일기를 자동 작성합니다.

### 🗓️ 비주얼 포토 캘린더 (Calendar-First)
* **일기 중심 표출:** 특정 날짜에 '일기'가 생성되어야 캘린더에 사진이 노출되는 구조로 데이터 무결성을 확보합니다. 다견 기록 시 썸네일에 프로필 이미지가 겹침(Stacked) 형태로 표시됩니다.
* **대표 사진(Representative Photo):** 한 날짜에 여러 장의 사진이 있어도 사용자가 선택한(혹은 AI가 추천한) 단 한 장의 사진이 캘린더 썸네일로 고정됩니다.
* **자동 동기화:** 사진 업로드 시 촬영 날짜를 파싱하여 해당 날짜의 캘린더 칸을 즉시 채웁니다.
* **활동 Heatmap:** GitHub 잔디처럼 사진이 많이 찍힌 날일수록 진한 색으로 표시됩니다.

### 🎞️ 성장 타임라인 (Growth Timeline)
* **전용 탭 분리:** 캘린더/지도와 독립된 별도의 타임라인 탭으로 제공합니다.
* **추가 데이터 Zero 원칙:** 기존 일기/사진 데이터만 활용하며 별도의 사용자 입력이 불필요합니다.

### 📍 공간 데이터 산책 포토맵 (Apple-Style Map)
* **위치 기반 시각화:** 지도 위에 해당 좌표에서 찍은 반려견 사진을 직접 표시합니다.
* **PostGIS 활용:** 사용자의 현재 지도 뷰포트 내에 존재하는 사진들만 효율적으로 필터링하여 노출합니다.

### 🍱 스마트 도감 & 선호도 아카이브 (Smart Inventory)
* **간식 도감:** 사진 스캔으로 제품명, 유통기한, kg당 권장 급여량을 자동 추출합니다.
